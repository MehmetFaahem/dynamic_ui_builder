# Blazor UI Builder

A dynamic UI component builder created with Blazor WebAssembly.

## Features

- **Drag and Drop UI Design**: Intuitive interface for creating UI layouts by dragging components onto a canvas
- **Component Properties**: Edit properties of UI components including size, position, colors, and text
- **Preview Mode**: View your UI design as it would appear to users
- **Local Storage**: Save and load UI designs from browser local storage
- **Responsive Layout**: Supports different canvas sizes for various device targets

## Components Available

- Button
- TextBox
- Label
- Dropdown
- Checkbox
- RadioButton

## Technical Implementation

- Blazor WebAssembly for client-side .NET execution
- C# models for component representation
- JSON serialization for storing form layouts
- Bootstrap for responsive styling
- Custom drag and drop implementation

## Getting Started

1. Clone the repository
2. Run the application using `dotnet run`
3. Navigate to the UI Builder in your browser
4. Start designing by dragging components from the left panel onto the canvas
5. Configure component properties in the right panel
6. Save your work using the toolbar buttons
